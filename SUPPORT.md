# Support

Accessible est publie comme application locale. Les donnees restent sur l'appareil de l'utilisateur et l'application ne depend pas d'un serveur applicatif.

## Demander de l'aide

Utiliser les issues GitHub du depot pour :

- signaler un bug ;
- demander une amelioration ;
- poser une question d'installation ;
- partager une incompatibilite materielle ou systeme.

Avant d'ouvrir une issue, verifier :

- la version d'Accessible utilisee ;
- le systeme d'exploitation et son architecture ;
- le fichier installe (`.exe`, `.msi`, `.dmg`, `.AppImage`, `.deb`) ;
- si le probleme concerne une fonction optionnelle : les moteurs externes installes localement.

## Securite

Ne pas publier publiquement de donnees sensibles, fichiers personnels ou details exploitables. Voir `SECURITY.md` pour le signalement de vulnerabilites.
