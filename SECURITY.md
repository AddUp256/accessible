# Security Policy

Accessible est une application locale sans telemetrie ni serveur applicatif.

## Versions supportees

| Version | Statut |
| --- | --- |
| 0.1.x | Pre-release supportee |

## Signaler une vulnerabilite

Utiliser en priorite le signalement prive GitHub du depot, si l'option "Private vulnerability reporting" est activee.

Si ce canal n'est pas disponible, contacter directement le mainteneur du depot via le profil GitHub ou le canal indique dans la page du projet. Eviter de publier publiquement des details exploitables avant correction.

## Donnees locales

Les profils, notes et exports restent sur l'appareil de l'utilisateur. Voir `PRIVACY.md` pour le modele de donnees et les limites du chiffrement local.
